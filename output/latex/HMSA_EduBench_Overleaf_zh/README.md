# HMSA 中文论文 Overleaf 项目

本文按 CCF-A 论文写作与证据标准组织为一篇可独立阅读的教育五级评分受控实证研究。稿件明确承认 soft-label auxiliary multi-task learning 的既有工作，不把双头结构表述为新的通用架构。正文主证据是在同一固定划分、配置和随机种子下比较 Hard-only 与 HMSA，并加入仅在开发集评估的 Shuffled-soft 与 MeanAux 两项事后机制对照。相关教育评审研究以正常文献关系交代任务动机，不呈现内部实验编号或研发过程。

## 直接导入 Overleaf

1. 在 Overleaf 中选择 **New Project → Upload Project**。
2. 上传本项目的 ZIP 文件，或将整个文件夹压缩后上传。
3. 将主文档设置为 `main.tex`。
4. 编译器选择 **XeLaTeX**。

正文、表格与矢量图已经包含在项目中；在 Overleaf 上编译论文不需要运行 Python。

## 目录

- `main.tex`：已吸收本轮审阅意见的中文论文正文。
- `figures/`：正文使用的 PDF 矢量图，以及用于快速预览的 PNG。
- `tables/`：由冻结结果生成的 LaTeX 表格。
- `data/`：冻结开发集/测试集报告和机械导出的 CSV。
- `scripts/`：结果导出、制表和绘图代码。
- `WRITING_NOTES.md`：投稿前需人工确认的内容与论断边界。

## 图表风格

新图采用克制的论文图表规范：

- 结果图以中性灰表示 Hard-only，以低饱和深蓝 `#3C5488` 表示 HMSA；
- 结构图用深蓝表示硬标签主路径、低饱和青绿色表示训练期分布辅助路径；
- 三幅图统一使用嵌入式 DejaVu Sans，按论文最终全宽尺寸生成，避免在 LaTeX 中大幅缩小后出现微小文字；
- 使用颜色与圆点/菱形的双重编码，保证灰度打印和色觉差异下仍可辨认；
- 正文优先嵌入矢量 PDF。

## 重新生成图表（可选）

需要 Python 3，以及 `numpy` 和 `matplotlib`：

```bash
python scripts/build_figures.py
python scripts/build_tables.py
python scripts/build_question_cluster_bootstrap.py
python scripts/audit_mean_distribution_equivalence.py
```

`scripts/export_frozen_results.py` 只从仓库中的冻结实验报告机械导出论文数据。它不会重新打开原始测试集。若项目已脱离原实验仓库，不需要运行该脚本。

## 证据口径

- 主对照：当前划分上、三个相同随机种子的 Hard-only 与 HMSA。
- 数据划分：训练集、开发集和测试集分别为 2,654、664 和 2,218 条；正文所有方法使用完全相同的数据行和输入，当前测试集 1--5 分样本数为 56、47、194、720 和 1,201。
- 相关审计研究用于交代任务动机并提供同任务系统结果；GPT-4o、DeepSeek-R1、DeepSeek-V3、QwQ-plus 和 EduBenchEvaluator 的文献值只用于性能定位，不能替代 Hard-only--HMSA 的受控配对证据。
- Direct-soft/Single-head mix：仅随机种子 42 诊断，不是正式多种子消融。
- Shuffled-soft：事后开发集机制对照；固定各硬标签内软目标多重集，只打乱训练样本与软目标的对应，三个模型种子共享同一映射。
- MeanAux：事后开发集目标对照；保持双头容量、初始化方式和硬头路径，以连续人类均分及 Smooth L1 替换经验分布交叉熵。最初的 seed 42 计算节约门槛在读取结果前由书面三种子并行修订取代；三个种子均完整报告，seed 42 未通过原门槛，因此没有访问测试集。
- 正式测试协议：检查点选择与实验配置均基于开发集；规则锁定后，在同一正式评测流程中计算两种配置、三个随机种子的测试结果。
- bootstrap：三个随机种子的逐行差值先取均值，同时提供按测试条目和按 163 个问题簇进行的 10,000 次配对自助重采样；两者均不估计训练随机性的总体不确定性。
- 目标信息审计：当前评分模式只有完全一致或相邻等级 2:1；连续人类均分与经验评分分布在训练集、开发集和测试集内均一一对应，因此不能声称分布比连续均分包含更多标签信息。
- 冻结 JSON/CSV 为保持与实验审计链一致，仍可能保留 `b0`、`exp51` 等旧机器键；正文、表格与图中统一映射为 Hard-only 与 HMSA。
- 新颖性口径：贡献是教育序数评分中的受控方法验证、误差分层与冻结评测证据，而不是首次提出 hard-main/soft-auxiliary 双头范式。
- 机制口径：可以说标签内置换支持样本级细粒度人类目标对应在一般辅助正则化之外提供开发集增量；MeanAux 结果支持目标表示与损失几何影响训练效果。由于 MeanAux 同时改变目标参数化和损失函数，不能把结果写成额外信息优势、独立测试确认或唯一因果机制。
- 评分路径：正文模型选择、最终整数评分和评价指标只读取硬头；冻结评测器保留软头诊断量，但不将其用于评分决策。
- 复现边界：冻结产物没有保存自动混合精度的最终解析值、上游模型/tokenizer revision、精确 PyTorch/Transformers 版本和 GPU 型号，正文已如实披露，不能用当前本机环境反推。
